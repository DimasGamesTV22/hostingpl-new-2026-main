# Требования к железу

## Панель (`panel`)

Панель сама по себе лёгкая — она не запускает игровые процессы, только управляет ими.
Основной потребитель памяти — PHP-FPM и очереди.

| Ресурс | Минимум | Старт (50–150 серверов) | Прод (500–2000 серверов) |
|---|---|---|---|
| vCPU | 1 | 2 | 4+ |
| RAM | 2 ГБ | 4 ГБ | 8+ ГБ |
| Диск | 20 ГБ SSD | 60 ГБ SSD | 120+ ГБ NVMe |
| Сеть | 100 Мбит/с | 300 Мбит/с | 1 Гбит/с |
| ОС | Debian 11 (bullseye) | Debian 12/13, Ubuntu 22.04/24.04 (x86_64) | |

Диск панели растёт только от логов установки, истории и метрик (около **40 МБ на 1000 серверов в год**).
Файлы игр и бэкапы на панель не кладутся — они на нодах.

Почему так мало:
- Метрики сырые — в Redis с TTL 7 дней, из MySQL вытесняются через час.
- Логи панели — ротируются, 30 дней.
- Картинки и вложения — на S3.

## Нода игровых серверов (`agent`)

Зависит от того, что вы гоняете. Ниже — реальные цифры.

| Игра | RAM на сервер | CPU | Игроков |
|---|---|---|---|
| Minecraft (vanilla) | 1–1.5 ГБ / 20 игроков | ~0.5 ядра | 20 |
| Minecraft (Paper, плагины) | 2–4 ГБ / 50 игроков | ~1 ядро | 50 |
| Minecraft Bedrock (PocketMine) | 1–2 ГБ | ~0.6 ядра | 30 |
| CS2 | 2 ГБ | ~1 ядро | 24 |
| MTA:SA | 1 ГБ | ~0.5 ядра | 64 |
| GTA SAMP | 700 МБ – 1.5 ГБ | ~0.6 ядра | 100 |
| GTA CRMP / RAGEMP | 3–6 ГБ | ~1.5–2 ядра | 100–200 |
| ALT-V (ALTV) | 2–4 ГБ | ~1.5 ядра | 64 |
| Rust | 6–10 ГБ | 2–3 ядра | 80 |
| Unturned | 2–4 ГБ | 1–1.5 ядра | 24 |
| ARK | 8–16 ГБ | 3–4 ядра | 70 |

**Правило планирования:** разделите физический RAM на 4 ГБ служебных (ОС, Docker, агент, MySQL
если локально, кэш страниц) и остальное делите на реальное потребление игры.
При 1 ГБ на игрока получите норм, при 300 МБ — лаги и OOM в контейнере.

Ориентир по нодам:

| Нода | Конфигурация | Сколько серверов |
|---|---|---|
| Starter | 4 vCPU / 8 ГБ / 60 ГБ NVMe | 4–6 Minecraft по 1.5 ГБ |
| Basic | 8 vCPU / 16 ГБ / 120 ГБ NVMe | 8–10 |
| Pro | 16 vCPU / 64 ГБ / 480 ГБ NVMe | 20–30 тяжёлых |

## Рантаймы: что нужно на ноде

| Рантайм | Требования |
|---|---|
| `docker` (по умолчанию) | Docker Engine 26+, плагин cgroup v2, `/var/lib/docker` на SSD |
| `podman` | Podman 5+, rootless тоже работает, systemd-юниты через quadlet |
| `lxc` | Proxmox VE 8+, включённый `pve-container`, шаблоны Debian 12/13 |
| `native` | systemd 252+, cgroup v2, `systemd-run` для изоляции, без Docker |
| `native` на Debian 11 | то же, но cgroup v2 нужно включить вручную (в bullseye он по умолчанию выключен) |

Агент: Node.js 20 LTS, 128 МБ RAM в покое.

## Внешние сервисы (опционально)

| Сервис | Зачем | Что будет без него |
|---|---|---|
| MySQL 8 | Данные | Работает, но не рекомендуем (MariaDB 10.11+ — ок) |
| Redis 7 | Сессии, кэш, очереди, метрики | Файловый кэш, синхронные задачи, метрики в MySQL (медленно) |
| S3-совместимое | Аватары, вложения, бэкапы | Локальное хранилище, бэкапы только на ноде |
| SMTP | Письма (подтверждение, чеки) | Логи в файл, юзер не видит подтверждение |
| Telegram Bot | Алерты, приём оплаты | Только email |
| Cloudflare | CDN, DDoS, бесплатный SSL | Nginx + Let's Encrypt |
| ЮKassa / Тинькофф | Карты | Только Криптобот или ручной приём |

## Портовое окружение панели

| Порт | Сервис |
|---|---|
| 80 / 443 | Nginx (публичный) |
| 22 | SSH |
| 3306 | MySQL (только localhost или приватная сеть) |
| 6379 | Redis (только localhost или приватная сеть) |
| 9000 | PHP-FPM (внутренний) |
| 9222 | Агент (WSS, только с панели — лучше через VPN/приватную сеть) |

Игровые порты (`game_port`, `query_port`, `rcon_port`) пробиваются на нодах диапазоном
из `config/hosting.php → ports.range` и пробрасываются в Nginx-стрим для лендинга.
